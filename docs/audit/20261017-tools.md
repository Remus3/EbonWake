## Sweep

- Non-object JSON state read with `.get` (TOOLS-02/03/08 pattern): every
  `read_json` / `json.loads` caller in the slice checked; the rest
  (`GateCache._trees`, `rotate_progress`, `rotate_daily`, `data_items`,
  `lane_progress`, `blocked_marker`, `launch_push`, `stall_of`) already
  guard with `isinstance`. `push_worker`'s re-read of push_worker.json is
  left as is: only the loop writes that file, atomically, always an object.
- Timestamp parsing (TOOLS-06): `epoch_of`, both `_epoch`s and `_age_s`
  fixed; `Tick.checklist.est` already suppresses ValueError / TypeError and
  only parses its own `iso()` output.
- Subprocess timeouts: every loop / gate / git call has one (600 s git,
  GATE_TIMEOUT_S gates, 60 s ls-remote, 3600 s OCR bench). leak_sweep's
  `_git` and schtasks calls have none; both are local, short and run by a
  hook or by hand (no finding).
- Atomic writes: loop state goes through `atomic_write`; JSONL ledgers are
  append-only by design.
- Bind address / ports: no tool binds; probes use 127.0.0.1 and
  `server.ew.ports`.
