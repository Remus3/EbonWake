Slice: tests/conftest.py, the tests helper module tests/ew_tiers.py and every
tests/test_[a-l]*.py file (57 files, 20509 lines before this change; the new
tests/ew_hermetic.py and tests/test_hermetic_p150.py are this plan's own).
tests/fixtures/ holds data only (no helper module). Method per
`docs/plans/150-audit-tests-a.md`: every file read in full (six read passes
of about 3.5k lines each, every candidate re-checked against the code before
it was accepted), each real finding fixed root-cause-first, then swept
across the slice.

Red-before-fix: TESTS-A-01 and TESTS-A-02 have new tests that were run red
before their fix (5 of the 6 tests in `tests/test_hermetic_p150.py`;
`test_explicit_roots_still_read_their_own_file` pins unchanged behaviour and
passed throughout; both new tests in `tests/test_ascii_lf.py`). The other
FIXED rows are defects IN a test (a vacuous or missing assertion, a missing
timeout, a leak): the corrected test is itself the pin. No red run is possible
there without first breaking the code under test, so the column says
"hygiene".

Game ToS floor: no finding. No test sends input to the game window, reads
game memory or client files, touches packets or calls an authenticated market
action; gamewatch / OCR tests use tmp dirs and fake tasklists, and
`test_gamewatch.test_module_never_touches_game_process` pins the floor.
