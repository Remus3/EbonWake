## Sweep (patterns of 01-05 across the slice)

- Promises that wait only for `end` (01): the only Node HTTP in the slice was
  main.js `getLocal` / `postLocal`; both now go through localhttp. The
  `restartServer` port-free wait and the watchdog both use `getLocal`.
- Untimed fetches (02): overlay.js `getJSON` is the slice's only fetch; the
  EventSource reconnects with `C.backoffMs` on error (unchanged).
- Non-atomic writes (03): main.js `logAutoRestart` already writes tmp then
  rename. The selftest PNG captures stay direct writes: they are throwaway
  images re-made every run, not state anything reads back.
- Class collisions (04, 05): every other repeated class in ew.css is either
  scoped (`.ew-game .ew-grow`, `.ew-grind .ew-rform`) or sets disjoint
  properties (`.ew-mcard` vs `.ew-card.ew-mcard`); `.ew-hit` is already pinned
  to one rule by shell.test.js.

## Checked and clean (no finding)

- Game ToS floor: the overlay is transparent, `focusable: false`,
  `setIgnoreMouseEvents(true)`, always-on-top; hotkeys are `globalShortcut`
  only; no input to any window, no hooks, memory, packets or client files.
  The overlay page makes read-only GETs to 127.0.0.1:8940 only (CSP
  `connect-src`).
- IPC: every `ipcMain.handle` checks `event.sender` against the dashboard;
  `ew:overlay-size` only from the overlay, number only, clamped. Preloads
  expose fixed channels (pinned by shell.test.js), sandboxed,
  `contextIsolation: true`, `nodeIntegration: false`; navigation and
  window.open are denied in both windows.
- HTML injection: overlay.js builds nodes with `textContent` /
  `createTextNode` only.
- Restart server: kills a pid only when `/api/version` answers the exact EW
  contract with the Ebonwake banner and it is not our own pid; spawn is
  hidden, detached, its `error` handled.
- Timers / listeners: overlay intervals are created once; the overlay
  `closed` handler checks identity so a reload does not null the new window.
- package.json: no install scripts, one dev dependency; non-ASCII / CRLF /
  machine paths / secrets: none in the slice.
