## Notes (checked, NOT-A-BUG)

- N1 app.py: bind is `("127.0.0.1", port)` only (make_server); Host check accepts
  127.0.0.1 / localhost / [::1] only; POST has no CORS header and OPTIONS is not
  answered; static `/app/*` resolves under APP_DIR (parents check, node_modules
  refused). OK.
- N2 app.py POST routes: a scratch probe fired 11 odd-typed values (None, ints,
  lists, dicts, bool, 1e308, 50-digit string) at every op of every POST route
  (1300+ requests) plus every GET route: every reply was 200 / 400 / 413, no
  dropped connection, no 500. No catch-all needed.
- N3 app.py:929 `fromisoformat(w["due_utc"])` outside the try: due_utc is
  produced by maintdigest `_iso` of a parsed datetime, always valid. OK.
- N4 app.py subprocess (`git rev-parse`): resolved from PATH, timeout 5 s,
  CREATE_NO_WINDOW. OK.
- N5 deadeye.py `_clean_read` keeps a stored read's `value` unvalidated; every
  consumer re-checks it (enhance.query takes fs_now only as an int 0..999;
  crons go through `_clean_crons`). OK.
- Game ToS floor: nothing in the slice reads game memory, sends input, touches
  packets or client files; detect.py checks existence only of the Documents
  `ScreenShot` folder / `GameOption.txt` and reads Steam's own manifests; every
  web call is an unauthenticated robots-gated GET. OK.
- ASCII / LF and no machine paths in the slice (tests/test_ascii_lf.py,
  leak sweep). OK.
