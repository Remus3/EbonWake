## Checked and clean (no finding)

- HTML injection: no `innerHTML` / `outerHTML` / `insertAdjacentHTML` in the slice except deadeye.js's preview, which is fed only by `C.renderMarkdown` (escapes first, safe tag subset, no links / images). Every other node is built with DOM APIs and `textContent`.
- Image sources (dashboard.js chip / card, deadeye.js gallery): every `src` comes from `C.portraitSrc`, which validates the id and builds `C.SERVER + /api/portraits/img/<encoded id>`; no data-supplied URL reaches an `img`.
- Writes: every POST goes through the preload bridge (`window.ewApi` via `EWToast.via`); no renderer `fetch` POST. External links open only through `EWToast.linkButton` (allowlisted https, plan 057); no in-dashboard navigation.
- Network: read-only GETs to the local EW server only (`C.SERVER`, 127.0.0.1). No market buy / sell / register call (ToS floor holds).
- Timers / listeners: each module installs its interval and bus listeners once (guarded by `S.timer` / `S.last` / `S.galleryBus`); a re-mount redraws only. Poll timers pause while hidden (`C.pollPaused`).
- Storage: every `localStorage` call sits in a try (deadeye.js drafts, dashboard.js tabs / collapse state); corrupt values fall back to defaults.
- Game ToS floor: nothing in the slice reads game memory, sends input, touches packets or client files. OCR reads only operator-saved screenshots, and its results are applied only by an explicit operator click.
- Non-ASCII / CRLF / machine paths: none in the slice.
