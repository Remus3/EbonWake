## Sweep (pattern of 01-04 across the slice)

Every plain-object map in the slice was checked for a lookup keyed by text
from the operator, OCR or an external notice: `reconcile`, `lootImportCounts`,
`claimRows` and `uniqueNamed` were the four (fixed above). The rest are
keyed by code literals, server-minted ids, EW-owned data or prefixed strings
(`marketHits` `id:sid`, `notifyLedger` rule-prefixed keys, `timerResets`
rule text, `suggestedRows` upper-case coupon codes, `noticeRows` urls and
`title\nends`, `validImpItems` numeric ids) or already use
`Object.prototype.hasOwnProperty` (`validPost`, `toastQueue`,
`validSettingsBody`, `WHATNOW_TABS`, `GAME_LABELS`, `preorderBadge`).
Output maps returned to callers stay plain objects (their shapes are pinned by
deepStrictEqual tests); only internal lookup maps changed.
