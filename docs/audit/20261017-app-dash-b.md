## Sweep (patterns of 01-03 across the slice)

- Overlapping polls (01): every other module re-arms a one-shot 60 s
  `setTimeout` per poll, so an overlap needs a GET hung for over 60 s and is
  bounded by tab visibility (`pollPaused`); toast.js was the only 5 s
  unconditional interval. No other change.
- Stale-closure set writes (02): no other module posts a whole set built from
  a draw-time capture (market / inventory / leveling / today send single-item
  bodies; leveling milestones post the typed text).
- Disabled-until-redraw buttons (03): imperial.js, home.js and today.js clear
  their busy / pending state and redraw on failure; overrides.js redraws in
  `finally`. Only progress.js `claim` relied on a redraw that a failure skips.

## Checked and clean (no finding)

- HTML injection: no `innerHTML` / `insertAdjacentHTML` / `document.write` in
  the slice; every node is built with `textContent` (static tests pin it).
- Writes: every POST goes through `window.ewApi` (`EWToast.via(b).post`), one
  literal allowlisted route each; validated again in main (`core.validPost`).
- Game ToS floor: palette Ctrl+K is a dashboard-window keydown, no global
  hotkey; nothing in the slice sends input to the game, reads memory, packets
  or client files. Market is read-only (no buy / sell / register route).
- CSP (index.html): `connect-src` only `http://127.0.0.1:8940`, scripts
  `'self'`.
- Timers / listeners: module intervals are created once per page (guarded by
  `S.timer` / `S.last`); remounts reuse them. Two-click delete timers reset
  their own button only.
- Time: reset maths are UTC; local display paths are tested in a fixed zone.
- Non-ASCII / CRLF / machine paths / secrets: none in the slice.
